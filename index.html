Tentang Aplikasi

Solusi Lengkap untuk Percetakan Modern

Tirta Apps dirancang khusus untuk mempercepat dan mengintegrasikan operasional percetakan Anda — dari kalkulasi harga otomatis hingga manajemen kasir multi-komputer.

📄

Perhitungan Otomatis Files

Deteksi otomatis jenis kertas, ukuran kertas, dan harga file untuk transaksi yang lebih cepat dan akurat.

🖨️

Manajemen Printer

Kelola printer untuk setiap ukuran kertas secara terpusat, mendukung operasional printing yang efisien.

💰

Sistem Kasir

Multi Kasir

Jalankan beberapa kasir dengan sinkronisasi data otomatis antar komputer pada jaringan lokal.

Panduan

Panduan Instalasi

Ikuti langkah-langkah berikut untuk menginstal dan mengkonfigurasi Tirta Apps.

Langkah Instalasi

  1. Download file installer dari tombol di atas.
  2. Jalankan file setup yang telah diunduh.
  3. Ikuti proses instalasi sampai selesai.
  4. Buka aplikasi Tirta Apps.
  5. Ikuti konfigurasi awal.
  6. Mulai menggunakan aplikasi.

Konfigurasi Awal

  • Buka Settings.
  • Atur Printer.
  • Atur Nota.
  • Atur QRIS Statis.
  • Buka Menu.
  • Edit Harga.
  • Atur harga kertas.
  • Lakukan test print untuk memastikan konfigurasi berjalan.
